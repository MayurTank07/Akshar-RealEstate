## Search Console Setup

Use `GOOGLE_SEARCH_CONSOLE_SETUP.md` for the full setup guide:

1. Add a Domain Property for `aksharestate.in`.
2. Verify with DNS TXT.
3. Submit `https://www.aksharestate.in/sitemap.xml`.
4. Inspect homepage, priority city pages, priority location pages and important property pages.
5. Run Test Live URL.
6. Request indexing only for indexable URLs with active inventory.
7. Monitor Page Indexing, Sitemaps, HTTPS, Core Web Vitals and Enhancements.

## Known Limitations

- Google Search Console data was not available locally, so CTR/impression optimization could not be data-driven.
- Backend location master records still show many locations as `needsVerification`; frontend rollout config is currently the source of SEO page verification.
- Full visual mobile/tablet/desktop screenshots were not run because Playwright is not installed in the project.
- Production admin/supervisor destructive actions were not run; CRUD was tested locally with seeded credentials and temporary demo data.
- Some public properties have no direct assigned supervisor phone, so the public view uses Akshar Estate fallback contact.

## Rollback Instructions

1. Identify the last stable frontend commit before the rollout.
2. Revert the latest frontend commit with `git revert <commit_sha>`.
3. Push `main` to trigger a fresh Vercel deployment.
4. Confirm `/sitemap.xml`, important property URLs and priority location pages return the expected status.
5. If backend changes are ever involved, revert the backend commit separately and redeploy the Render service.
